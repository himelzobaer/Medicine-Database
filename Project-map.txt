--------------------------------------------------------------------------------
🔄 SYSTEM WORKFLOW
--------------------------------------------------------------------------------
1. GitHub Action triggers `pnpm run scrape:detail --time-limit=55`
2. Scraper queries `medicine.db` for unenriched URLs (unit_price is NULL).
3. HTTP Client fetches HTML (with delays to avoid bans).
4. Cheerio parses HTML into Zod validated objects.
5. Drizzle updates `medicine.db`.
6. GitHub Action runs `pnpm run export:all` -> Updates JSON/CSV.
7. GitHub Action commits and pushes changes.
8. (Future) Supabase sync script pushes new changes to cloud Postgres.
9. (Future) Next.js web app consumes from Supabase API.
